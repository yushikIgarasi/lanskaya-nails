# Вероника Ланская — сайт nail-мастера

Одностраничный сайт мастера маникюра: баннер, о мастере, услуги и цены, портфолио, запись с календарём, карта и контакты.
Чистые HTML, CSS и JavaScript. Сборка не нужна, зависимостей нет.

## Структура

```
index.html        страница
css/style.css     все стили и адаптация
js/main.js        форма записи (уходит в Telegram), календарь, просмотр портфолио, меню
fonts/            шрифт Majestic для надписей
img/              картинки в формате WebP
img/works/        работы для портфолио
robots.txt        правила для поисковиков
.nojekyll         нужен GitHub Pages, чтобы отдавать файлы как есть
```

## Запустить у себя

Нужен любой локальный сервер. Например, если установлен Python:

```bash
python -m http.server 5173
```

Дальше откройте http://localhost:5173/.

## Выложить на GitHub Pages

1. Создайте на GitHub новый репозиторий (например, `lanskaya-nails`) и загрузите в него содержимое этой папки.2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через минуту-две сайт откроется по адресу `https://ВАШ-НИК.github.io/lanskaya-nails/`.

Все пути в проекте относительные, поэтому сайт одинаково работает и по адресу с названием репозитория, и на своём домене.
Имена файлов должны совпадать с ссылками по регистру букв: GitHub Pages их различает, Windows нет.

## Что заменить на настоящее

Сейчас в сайте стоят примерные данные:

| Что | Где |
| --- | --- |
| Телефон `+7 (999) 123-45-67` | `index.html`, поиск по `tel:` и по `123-45-67` |
| Telegram `@lanskaya_nails` | `index.html` (ссылки) и `js/main.js` (переменная `TELEGRAM` вверху файла: сюда приходят заявки) |
| Адрес и часы работы | `index.html`, подвал |
| Карта | `index.html`, `iframe` в блоке записи: поменяйте координаты `ll=` и `pt=` в ссылке |
| Цены | `index.html`: список цен в разделе «Услуги» и список услуг в форме (они продублированы) |
| Фото работ | `img/works/01.webp` … `10.webp` и такие же `01-560.webp` … `10-560.webp` (маленькие версии для телефонов), подписи в `index.html` |
| Портрет и баннер | `img/portrait.webp`, `img/hero-bg.webp` и `img/hero-bg-800.webp` |

Форма пока не отправляет заявку на сервер: она открывает Telegram с уже написанным сообщением, мастеру остаётся нажать «Отправить».

## Что добавить, когда появится адрес сайта

- `<link rel="canonical" href="https://ВАШ-АДРЕС/">` в `<head>` страницы.
- `og:url` и `og:image` с полным адресом картинки для превью ссылки в мессенджерах.
- `sitemap.xml` и строку `Sitemap:` в `robots.txt`.

## Шрифты и картинки

- Manrope подключается с Google Fonts, поэтому у посетителя должен быть интернет.
- Шрифт Majestic лежит в `fonts/majestic.woff2`. Проверьте, что его лицензия разрешает использование на сайте, прежде чем публиковать репозиторий.
- Фото в портфолио нужно публиковать только с согласия тех, кто на них изображён.

## Адаптация

Макет масштабируется пропорционально на широких экранах, отдельные правила есть для ширины до 1023, 767, 520 и 380 пикселей. Минимальная поддерживаемая ширина 320 px.
